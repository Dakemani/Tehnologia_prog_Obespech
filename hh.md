mindmap
  root((Процессор))
    Black Box Testing
      Работает ли процессор после установки?
      Запускается ли компьютер?
      Выполняет ли процессор вычисления?
      Правильно ли обрабатывает команды?
      Неизвестно, как устроен процессор внутри?

    Functional Testing
      Правильно ли выполняет арифметические операции?
      Работают ли все ядра?
      Работают ли потоки?
      Правильно ли обрабатывает инструкции?
      Работает ли встроенная графика?
      Корректно ли работает кэш?

    Usability Testing
      Легко ли установить процессор?
      Удобно ли наносить термопасту?
      Легко ли установить систему охлаждения?
      Понятна ли маркировка процессора?
      Удобно ли снимать процессор?

    Compatibility Testing
      Совместим ли с материнской платой?
      Подходит ли сокет?
      Поддерживает ли оперативную память?
      Совместим ли с системой охлаждения?
      Поддерживается ли BIOS?
      Работает ли с операционными системами?

    Performance Testing
      Какая максимальная частота процессора?
      Сколько операций выполняет за секунду?
      Как быстро запускает программы?
      Как справляется с играми?
      Какова производительность в многопоточных задачах?
      Какова температура под нагрузкой?

    Component Testing
      Проверить каждое ядро отдельно
      Проверить каждый поток
      Проверить работу кэш-памяти
      Проверить встроенный контроллер памяти
      Проверить встроенную графику
      Проверить работу контроллера PCI Express

    Integration Testing
      Работает ли процессор вместе с материнской платой?
      Правильно ли взаимодействует с оперативной памятью?
      Работает ли вместе с видеокартой?
      Корректно ли работает с системой охлаждения?
      Правильно ли взаимодействует с накопителями?

    Documentation Testing
      Есть ли инструкция по установке?
      Указан ли тип сокета?
      Указаны ли характеристики?
      Есть ли информация о максимальной температуре?
      Указана ли поддерживаемая оперативная память?

    Stress Testing
      Запустить процессор на 100% нагрузки
      Проверить работу под длительной нагрузкой
      Проверить максимальную температуру
      Проверить стабильность при разгоне
      Проверить работу всех ядер одновременно

    Negative Testing
      Попытаться запустить с неподдерживаемой материнской платой
      Проверить работу при перегреве
      Проверить работу при недостаточном питании
      Попробовать установить процессор неправильно
      Проверить поведение при повреждении контактов

    Security Testing
      Проверить защиту от уязвимостей
      Проверить защиту от вредоносных инструкций
      Проверить работу механизмов безопасности
      Проверить наличие уязвимостей Spectre и Meltdown

    Verification
      Соответствует ли процессор заявленным характеристикам?
      Правильно ли работает заявленное количество ядер?
      Соответствует ли частота заявленной?
      Соответствует ли объём кэш-памяти?
      Соответствует ли энергопотребление спецификациям?

    Validation
      Подходит ли процессор для игр?
      Подходит ли для работы с графикой?
      Справляется ли с программированием?
      Подходит ли для монтажа видео?
      Удовлетворяет ли требованиям пользователя?

    Automated Testing
      Автоматический запуск тестов производительности
      Автоматическая проверка температуры
      Автоматическая проверка стабильности
      Автоматическая проверка работы ядер
      Автоматическое сравнение результатов

    Beta Testing
      Передать процессор тестировщикам
      Проверить работу в разных компьютерах
      Проверить в различных играх
      Собрать отзывы пользователей
      Выявить ошибки до массового выпуска
